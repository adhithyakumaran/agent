# Architecture Decision Records

Create an ADR when a change affects:

- Layer boundaries or dependency direction
- Port contracts
- Run or event semantics
- Persistence or artifact layout
- Domain-pack contracts

Naming: `NNNN-short-title.md` (e.g. `0001-import-boundary-tooling.md`).

P0.1 uses dependency-cruiser for boundaries; no ADR required unless the mechanism changes.
